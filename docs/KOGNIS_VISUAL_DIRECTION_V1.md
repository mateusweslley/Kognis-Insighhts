# KOGNIS_VISUAL_DIRECTION_V1

## Status

Versão: V1

Fase: R0.7

Objetivo:

Traduzir referências visuais em diretrizes práticas para o relayout do Kognis.

Referências analisadas:

* Meeting Automation SaaS UX/UI Design
* Nep Logistics Financial Intelligence Platform

---

# 1. Mudança De Mentalidade

O Kognis não deve ser construído como:

```text
Sistema
↓
Menu
↓
Tabela
↓
CRUD
```

O Kognis deve ser construído como:

```text
Pergunta
↓
Descoberta
↓
Insight
↓
Ação
```

O usuário não entra para gerenciar formulários.

O usuário entra para entender seus clientes.

---

# 2. Princípio Visual Principal

Toda tela deve responder:

> "O que eu preciso saber agora?"

Antes de responder:

> "O que eu posso configurar?"

---

# 3. Estrutura De Hierarquia

Cada página deve seguir:

```text
Título

Contexto

Métricas

Insight Principal

Conteúdo Operacional
```

Nunca:

```text
Título

Tabela

Tabela

Tabela

Botão
```

---

# 4. Filosofia De Cards

Os cards são a unidade principal do produto.

Todo card deve transmitir:

* Clareza
* Espaço
* Prioridade

Estrutura:

```text
Título

Valor

Contexto

Ação opcional
```

---

# 5. Dashboard Futuro

O Dashboard não deve mostrar:

```text
12 pesquisas
32 respostas
5 campanhas
```

Isso é sistema.

O Dashboard deve mostrar:

```text
70% dos clientes são mulheres

Cidade mais frequente:
Maracanaú

Avaliação média:
4.8

Produto mais citado:
Vestido Floral
```

Isso é inteligência.

---

# 6. Uso De Cores

A cor roxa não é decoração.

A cor roxa indica:

* foco
* destaque
* ação principal

Limite:

Uma área de destaque principal por tela.

---

# 7. Uso De Branco

O branco é protagonista.

O Kognis deve parecer leve.

Regras:

* Muito espaço negativo.
* Containers respirando.
* Pouca informação por bloco.

---

# 8. Visualização De Dados

Gráficos devem responder perguntas.

Exemplo ruim:

```text
Gráfico de pizza
```

sem contexto.

Exemplo correto:

```text
Quem compra mais?

72% Feminino
28% Masculino
```

---

# 9. Busca

Busca deve ser tratada como componente estratégico.

A busca não é acessório.

Ela deve aparecer em destaque nas áreas:

* Pesquisas
* Respostas
* Dashboard futuro

---

# 10. Empty States

Toda tela vazia deve ensinar o próximo passo.

Exemplo:

```text
Nenhuma resposta recebida

Imprima o QR Code ou compartilhe o link para começar a coletar respostas.

[ Ver QR Code ]
```

---

# 11. Insight Cards

Novo componente obrigatório.

Estrutura:

```text
Ícone

Título

Insight

Ação
```

Exemplo:

```text
🎯 Público principal

65% dos respondentes têm entre 19 e 29 anos.

[ Ver detalhes ]
```

---

# 12. Navegação

A navegação deve parecer produto SaaS.

Não ERP.

Prioridades:

```text
Dashboard

Pesquisas

Respostas

Campanhas

Configurações
```

---

# 13. Linguagem Visual

Evitar:

* excesso de bordas
* excesso de divisórias
* excesso de ícones
* excesso de badges

Preferir:

* agrupamento visual
* contraste
* espaçamento
* hierarquia

---

# 14. Linguagem De Produto

Trocar mentalidade:

De:

```text
Gerenciar pesquisa
```

Para:

```text
Entender clientes
```

De:

```text
Visualizar respostas
```

Para:

```text
Descobrir padrões
```

De:

```text
Exportar CSV
```

Para:

```text
Levar dados para análise
```

---

# 15. Objetivo Final

Quando um usuário abrir o Kognis pela primeira vez, ele deve pensar:

> "Esta plataforma me ajuda a entender meus clientes."

E não:

> "Esta plataforma cria formulários."
